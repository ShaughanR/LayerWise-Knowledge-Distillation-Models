# LayerWise-Knowledge-Distillation-Models
Employs layer-wise knowledge distillation techniques between a MSDF Tiny-Swin Transformer teacher model and a ResNet-18 student model. Multiple student models were developed (base ResNet-18, Layer-Wise KD ResNet-18, Layer-Wise KD MSDF ResNet-18) to highlight the specific benefits provided by knowledge distillation as well as the benefits different architectures provide in the knowledge distillation pipeline.
