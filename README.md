# LayerWise-Knowledge-Distillation-Models
Employs layer-wise knowledge distillation techniques between a MSDF Tiny-Swin Transformer teacher model and a base ResNet-18 student model. Multiple student models were developed (base ResNet-18, Layer-Wise KD ResNet-18, Layer-Wise KD MSDFResNet-18) to highlight the specific benefits provided by knowledge distillation as well as the benefits different architectures provide in the knowledge distillation pipeline. Each model is provided with the current configuration set up for training on the AID: A Scene Classification dataset. To use these models, first run the teacher model to collect the .pt file containing the pretrained weights used for knowledge distillation with the student models. The hyperparameters can be changed in the Train method call of the teacher model at the bottom of its respective file. Then, run the student models. The recorded performance metrics include model parameters, test accuracy, Cohen's kappa score, macro_f1 score, accumulated loss, and training time.
